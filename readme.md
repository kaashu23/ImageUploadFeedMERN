# 📸 Social Feed App (MERN Stack)

A modern Pinterest/Instagram-style feed application where users can upload images with captions and view them in a responsive masonry layout.

---

## 🚀 Features

- 📤 Upload image with caption
- 🖼️ Masonry/Pinterest-style feed layout
- ⚡ Real-time-like updates (polling)
- 🎨 Modern UI with hover effects
- 🌐 REST API using Express.js
- ☁️ Image upload support (ImageKit / Multer)
- 🗄️ MongoDB database integration

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- CSS (Masonry Layout + Modern UI)

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- Multer (file upload)
- ImageKit (image hosting)
